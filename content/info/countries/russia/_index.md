# Россия

Исторически в развитии интеллектуального движения в России можно выделить три «ветки». Первое началось в 2001 году и закончилось в 2020-м, когда из-за ковида не удалось провести XX чемпионат. Оно было тесно связано с Международной ассоциацией клубов «Что? Где? Когда?», все чемпионаты проводились по лицензии этой организации. 

Две остальных появились в 2023 году, уже после раскола движения. В одной продолжали проводить чемпионаты России по спортивному «Что? Где? Когда?», но уже по лицензии телекомпании «Игра-ТВ», в другой проводились ЧР по интеллектуальным играм, в рамках которых проводились турниры по командной викторине с раундами по минуте.
